# Godzilla

Named an official tourism ambassador of Tokyo, Godzilla has been called the
"Pride of Japan". That name first came from the mayor of Shinjuku, a Tokyo
ward that Godzilla has destroyed in multiple films.

Fun fact: Atlassian's [Jira][jira] gets its name from *Gojira*, the Japanese
name for Godzilla. It started as an alternate name for Mozilla's bug
tracking software, [Bugzilla][bz].
